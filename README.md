# Dino Chase

Dino Chase is a Java-based multiplayer game project built using a client-server structure. The game allows players to connect through a client, interact with the game panel, and compete with leaderboard functionality.

## Features

- Multiplayer gameplay support
- Java client-server architecture
- Player handling system
- Game panel interface
- Leaderboard functionality
- Object-oriented project structure

## Technologies Used

- Java
- Java Swing / GUI components
- Object-Oriented Programming
- Client-server networking
